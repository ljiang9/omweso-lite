# omweso-lite

简化版乌干达播棋 **Omweso**（mancala 家族），纯 Python 标准库实现。

## 玩法

- 2×8 棋盘，每坑开局 4 子，共 64 子。你是**南**（下排），AI 是北。
- 输入坑号 `1-8` 走子，逆时针播种，每坑放 1 子。
- **接力播种**：最后一子若落在播种前非空的坑，抓起该坑全部子继续播，直到落在空坑。
- **吃子**：最后一子落在自己一侧的空坑，吃掉该子 + 正对面坑的全部子。
- 轮到一方而己侧无子可走，或达到 600 半回合上限 → 终局；双方收回己侧残子，吃子+残子多者胜。

## 用法

```bash
python3 -m omweso_lite                 # 人机对战（需要终端）
python3 -m omweso_lite --auto --games 10 --seed 42            # AI 对 AI
python3 -m omweso_lite --auto --games 10 --seed 7 --verbose   # 打印每局
```

## 真实验证记录

- `py_compile` 通过。
- 23 项单元测试全过（/tmp/test_omweso.py）：开局 64 子、坑号↔位置映射、播种分布、
  接力触发（落非空坑继续播）、吃子（己方空坑吃 1+对面）、对方侧空坑不吃子、
  空坑/越界走法抛 `ValueError`、无子可走判终局、终局收回残子、3 个种子完整对局种子守恒。
- `--auto --games 10 --seed 42`：10 局全部自然结束，南胜 5 / 北胜 2（seed 7）/ 和棋 0，无崩溃。
- 交互模式在非终端下中文提示并 exit 2。

## 修复过的 bug

- **走法 API 不一致（真 bug）**：`legal_moves` 最初返回环位置（8–15），而 `apply_move`
  要坑号（0–7），`ai_choose` 混用会在玩家 1 回合抛 `ValueError`。已统一为坑号，
  单元测试 T9 抓到并回归锁定。

## 诚实局限

- **规则是简化版**：真实 Omweso 是 4×8 棋盘、有复杂的反向吃子与"种子不能动"等规则；
  本项目取 2×8 + 接力播种 + 简单吃子，不可当正史规则。
- AI 只是 1 步贪心（吃子数优先），不做深层搜索；接力让对局偏短（演示多在 20 半回合内结束）。
- 文本界面，无图形/存档/悔棋；Python 3.10+，纯标准库。
